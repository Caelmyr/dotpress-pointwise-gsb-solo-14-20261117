# DotPress 峰值内存对照记录

记录方式：`scripts/render_equivalence.py` 保留改造前的整体式实现作为 reference，
把 reference 与当前 `dotpress/core.py` 放在**各自全新的子进程**里，用同一张源图、
同一份设置、同一个测量区域跑一次完整渲染；峰值取子进程 `/proc/self/status` 的
`VmHWM`（不用 `ru_maxrss`：fork 后子进程会继承父进程的高水位，会虚高）。
逐通道 PNG 用 SHA-256 比对，统计与区域测量按字典逐值比对。复现：

```
python3 scripts/render_equivalence.py --check \
    --source <同尺寸源图.png> --settings <同设置.json> --json out.json
```

## 同一张接近上限的图、同样设置

源图 4000×4000 RGBA；页面 1200×1200（`1200*25.4/288` mm，288 DPI），24 LPI，
四版角度 15/75/0/45、相位与套准偏移均非零、网点扩大 0.12、gamma 0.95、
饱和 1.15、裁切 `[.03,.05,.98,.97]`、`fit=contain`。

| 实现 | 峰值 RSS | 相对 |
|---|---|---|
| 改造前整体式 | 1852.7 MB | 1.000 |
| 当前流式 | 295.4 MB | **0.159** |

同条件逐通道 PNG、整页统计、区域测量全部逐字节/逐值相同（`--check` 退出码 0）。

中等页面仍有约一半的峰值来自解码后的源图与 13 张全分辨率 PNG 通道缓冲，
两者在改造前后都必须存在；页面越接近 1200×1200 上限，被消掉的
四通道浮点中间量占比越大，因此题目要求的“接近上限”条件下稳定在 0.15–0.16。

## 未改变的语义

* 网角/相位/套准：分带使用物理 mm 绝对坐标并读取完整分色页，带边界不重新
  起网格；套准插值读完整页因此不缺邻域，页面外仍为 `constant` 零落墨。
* 渐变与透明边：源图逐带按完整页映射重采样，`inside` 掩码、预乘和纸色合成
  与整体式逐位一致。
* 网点扩大：仍先做对称中间调扩张再与网点阈值比较。
* 统计/页面/交付：报告、区域测量和 11 张交付 PNG 来自同一次完整分色与加网，
  分带尺寸（1、7、64、199 行）不改变任何输出像素（见回归测试）。
