# DotPress 印版工作台

DotPress把一张照片置入物理毫米页面，进行简化CMYK分色或自定专色墨组分色、旋转网线调幅加网与近似纸墨软打样。它用于教学、艺术版画方案比较，不是ICC印刷合同打样或光谱预测器。演示素材为程序合成。

运行：`docker compose up --build -d`，打开 http://127.0.0.1:18917/ 。独立具名卷保存工程；`DOTPRESS_DATA_DIR`选择目录，`PORT`选择端口。直接运行用`pip install -r requirements.txt && ./start.sh`。Python3.11/3.12均用requirements的解释器条件版本。

正常功能：照片/EXIF导入；纸张尺寸与DPI适配；归一化裁切和包含/铺满/拉伸；饱和与gamma色阶；黑版替代及总墨量限制；四独立灰度连续调版；物理mm旋转菱形AM网点；四版相位、套准位移及开关；网点扩大；纸色和墨密度软打样；局部覆盖测量及留存；名义量/实际网点直方统计；命名方案恢复；不可变修订结果历史；四版PNG/软打样/参数清单交付；含历史源图的独立可编辑工程往返；2至6罐具名具色专色墨组、有界最小二乘调墨、重建误差预览与交付清单；以及完整图像准备工作台。

专色模式（`separation=spot`）保留2至6罐自定墨，每罐有名称与`#RRGGBB`墨色（名称与颜色均不得重复）。分色不是把像素归到最近一罐，而是对每个像素求解`min ||Σ a_i·D_i − t||`：`D_i`为第i罐墨满版光学密度，`t`为页面颜色所需的密度；约束为`0 ≤ a_i ≤ 1`且`Σ a_i ≤ 总墨量上限`，因此墨量不会为负，总墨量仍受限。求解按墨干集枚举（至多三罐处于0与1之间，其余落0或1），再对仍有残差的像素补一次单罐满版搜索；这是精确的有界最小二乘解。若这组墨无法跨越某颜色，保留最佳拟合并由`error`图与`report.reconstruction`给出线性反射率RMSE（默认容差0.02，失败面积与平均/95%/最大误差），不虚报已还原。专色同样有独立网角、相位、套准与开关，画面软打样、单罐灰版/连续调版、误差图和下载包来自同一次分色。交付包为`ink01…inkNN`灰度版与`-tone`连续调版，`manifest.json`逐罐列出键名、名称、墨色、总墨量上限与实际最大总墨量；工程保存/导出的版本与该墨组一同往返。`separation=cmyk`保持原四色工作方式不变。

坐标是左上为原点、x右/y下的物理mm，像素中心`(column+.5,row+.5)*25.4/dpi`。网角和相位不随DPI任意重置。套准偏移同时平移该版色调与网格，页面外零落墨。灰度印版黑为墨、白为纸；RGB预览与线性数据版语义不同。RGBA源先在直线性光里与纸色合成再分色；隐形RGB不会漏入墨量。CMYK分色为简化GCR+比例总墨量；专色为上述有界最小二乘；两者的软打样都是墨透射率乘积的近似RGB模型，不含真实ICC设备特征。每次应用设置会失效当前结果，旧结果仍固定其原修订及参数，下载可指定结果。最多1200边/144万输出像素、源图1600万像素/20MB，工程20版本/64MB。专色求解时间随超色域面积增长，另设20万像素的精确补解预算，余量用首轮拟合；高LPI低DPI会产生采样混叠，当前为单点二值网点采样，不承诺印刷级抗混叠。

`image_lab/`、`templates/prepare.html`及准备工作台静态资源完整复用自有solo_16正常图像准备模块（不是MapMender地图模块）；其多帧、色彩、蒙版、几何及工程能力仍可在`/prepare`独立使用。DotPress业务在新`dotpress/`及`press.*`，没有材质/图集/地图业务混入。复用逐文件哈希与后台有效行数报告由交付旁置提供；作者题目、对照和审题资料不在产品目录。
