# DotPress 印版工作台

DotPress把一张照片置入物理毫米页面，进行简化CMYK分色、旋转网线调幅加网与近似纸墨软打样。它用于教学、艺术版画方案比较，不是ICC印刷合同打样或光谱预测器。演示素材为程序合成。

运行：`docker compose up --build -d`，打开 http://127.0.0.1:18917/ 。独立具名卷保存工程；`DOTPRESS_DATA_DIR`选择目录，`PORT`选择端口。直接运行用`pip install -r requirements.txt && ./start.sh`。Python3.11/3.12均用requirements的解释器条件版本。

正常功能：照片/EXIF导入；纸张尺寸与DPI适配；归一化裁切和包含/铺满/拉伸；饱和与gamma色阶；黑版替代及总墨量限制；四独立灰度连续调版；物理mm旋转菱形AM网点；四版相位、套准位移及开关；网点扩大；纸色和墨密度软打样；局部覆盖测量及留存；名义量/实际网点直方统计；命名方案恢复；不可变修订结果历史；四版PNG/软打样/参数清单交付；含历史源图的独立可编辑工程往返；网花诊断与同区域前后对比预览；以及完整图像准备工作台。

坐标是左上为原点、x右/y下的物理mm，像素中心`(column+.5,row+.5)*25.4/dpi`。网角和相位不随DPI任意重置。套准偏移同时平移该版色调与网格，页面外零落墨。灰度印版黑为墨、白为纸；RGB预览与线性数据版语义不同。RGBA源先在直线性光里与纸色合成再分色；隐形RGB不会漏入墨量。当前分色为简化GCR+比例总墨量，软打样为固定RGB透射率乘积，不含真实ICC设备特征。每次应用设置会失效当前结果，旧结果仍固定其原修订及参数，下载可指定结果。最多1200边/144万输出像素、源图1600万像素/20MB，工程20版本/64MB。高LPI低DPI会产生采样混叠，当前为单点二值网点采样，不承诺印刷级抗混叠。

网花诊断（`dotpress/diagnosis.py`与`/press/projects/<id>/diagnose`系列接口）从当前设置真实渲染的二值印版与重叠预览出发，对所选归一化区域做加Hann窗的二维FFT，在低于半网频的低频带内提取显著峰，并与解析目录匹配：菱形格低阶谐波经像素网格折叠的单通道采样混叠（self_alias）、两通道谐波差的拍频（pair_beat），以及连续调预览中同样存在的图像内容峰（content）；不是简单相减两个网角。报告给出网花评分与等级、逐峰归因（周期/角度/网胞数/显著性）、通道对拍频贡献排序和各通道混叠比。区域过小、覆盖网胞不足、无墨/全墨、超过半数峰无法解释时标记`reliable=false`并列出原因；每网胞像素过低时明确提示网角无法消除混叠、需改DPI/LPI。建议网角在当前纸张、DPI与网线下用同一加网器对平网补丁仿真验证，按实测低频能量排序给出最多三组，附预期改善百分比与解析评分，改善不足5%会提示当前手动角度可能已接近条件极限。同区域前后对比图（软打样或单通道，左旧右新）即时渲染但不写盘；确认写回走`diagnose/apply`，请求须带诊断时返回的修订号与输入指纹（源图名+设置哈希），任一变化即409拒绝，写回只改四通道网角并留下`angle_advice`记录，旧结果仍固定在原修订，交付包仍可按旧结果下载。手动网角输入在诊断前后始终可用，诊断面板不接管表单。

`image_lab/`、`templates/prepare.html`及准备工作台静态资源完整复用自有solo_16正常图像准备模块（不是MapMender地图模块）；其多帧、色彩、蒙版、几何及工程能力仍可在`/prepare`独立使用。DotPress业务在新`dotpress/`及`press.*`，没有材质/图集/地图业务混入。复用逐文件哈希与后台有效行数报告由交付旁置提供；作者题目、对照和审题资料不在产品目录。
